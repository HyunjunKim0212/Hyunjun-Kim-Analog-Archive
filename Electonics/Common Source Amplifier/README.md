# Common-Source Amplifier with Source Degeneration
## Goal of this project
The goal of this project is to design and simulate a common-source amplifier using Cadence Virtuoso. The load resistor is set to 500 Ω, the signal resistor to 50 Ω, and the capacitor C_s to 1 pF. Vdd is equal to 1.3 V. I will assume a threshold voltage as 0.5 V and K' is equal to 350 $\mu A/V^2$.
